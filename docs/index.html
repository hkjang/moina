Offline first

컨테이너 하나로
폐쇄망까지

정적 React 앱과 Go API를 하나의 distroless 이미지에 담았습니다. 외부 PostgreSQL DSN과 bootstrap 정보, encryption key만 환경변수로 전달합니다.

해시 검증릴리스 본문의 SHA256과 반입 파일을 대조합니다.
이미지 로드docker load로 moina:v0.1.0을 등록합니다.
네 값으로 시작PostgreSQL DSN, 관리자 아이디·비밀번호, encryption key만 지정합니다.
화면에서 연결Keycloak, AI, 승인과 권한은 관리자 페이지에서 설정합니다.
# 1. 무결성 확인
sha256sum moina-v0.1.0.tar.gz

# 2. registry 접속 없이 로드
gzip -dc moina-v0.1.0.tar.gz |
  docker image load

# 3. 외부 PostgreSQL 연결
cp .env.example .env
docker compose --env-file .env \
  -f deploy/docker-compose.offline.yml \
  up -d --pull never

# 4. 준비 상태 확인
curl --fail 127.0.0.1:8080/readyz

Answers

자주 묻는 질문

도입 전에 가장 많이 확인하는 운영 조건을 짧게 정리했습니다.

MOINA는 완전한 폐쇄망에서 운영할 수 있나요?

핵심 SNS 기능은 외부 인터넷 없이 동작합니다. 외부 PostgreSQL과 내부 DNS/TLS만 필요합니다. Keycloak이나 AI를 쓰려면 폐쇄망 안에서 해당 endpoint가 도달 가능해야 합니다.

PostgreSQL 이미지도 릴리스에 포함되나요?

아닙니다. 기관이 운영·백업하는 외부 PostgreSQL을 DSN으로 연결합니다. GitHub Release에는 요청 범위대로 moina 서비스 이미지 tar.gz 하나만 포함됩니다.

Keycloak 설정 때문에 환경변수가 늘어나나요?

늘어나지 않습니다. issuer URL, client ID, client secret, redirect URL과 role mapping은 bootstrap 후 관리자 UI에서 저장합니다.

AI가 없어도 SNS를 쓸 수 있나요?

가능합니다. AI는 관리자가 켜는 선택 기능입니다. 끄면 Flow, Moin, Link, 검색, 알림과 운영 기능은 독립적으로 동작합니다.

승인 메뉴가 필요 없는 조직은 어떻게 하나요?

승인 정책을 끄면 검토·승인·반려 상태와 관련 메뉴가 사용자 흐름에서 제외됩니다. 켜면 지정 역할과 작업에만 적용됩니다.
