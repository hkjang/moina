MOINA 사용자 가이드

처음 로그인하는 순간부터 나만의 Flow를 만들고, 사람과 Topic을 Link하고, 개인 API·MCP 키를 안전하게 회전하는 과정까지 설명합니다.

버전 v0.1.5한국어 기본데스크톱·모바일약 12분

목차

핵심 용어로그인Flow와 Moin대화와 반응검색과 TopicMoim과 AI개인 설정알림 설정API·MCP 키안전 기능실제 화면문제 해결

1. MOINA의 핵심 용어

기존 SNS에서 익숙한 기능을 지식 중심의 언어로 정리했습니다. 기능의 의미는 달라지지 않아 바로 사용할 수 있습니다.

Moin짧은 생각·사진·링크를 공유하는 게시물
EchoMoin에 이어지는 답글
Remoin다른 사람의 Moin을 내 Flow로 확산
Link사람 또는 Topic을 팔로우
Flow나에게 흐르는 개인화 피드
Moim관심사 기반의 커뮤니티 공간
Pulse지금 주목받는 Topic
Pocket나중에 볼 Moin 저장함

2. 로그인과 첫 진입

로컬 계정

  1. 관리자가 전달한 서비스 주소의 로그인 화면을 엽니다.
  2. 아이디와 비밀번호를 입력합니다.
  3. 처음 로그인했다면 프로필의 표시 이름, 이메일과 소개를 확인합니다.

Keycloak SSO

관리자가 OIDC를 켜면 조직 계정으로 로그인 버튼이 표시됩니다. Keycloak 인증 뒤 원래 열려 있던 MOINA 경로로 돌아옵니다.

로그인 화면 아래에서 현재 서비스 버전을 확인할 수 있습니다. 지원 요청 시 `v0.1.5` 같은 전체 버전을 함께 전달하세요.

3. Flow와 첫 Moin

For Me는 정책을 통과한 최근 Moin 최대 200개에서 관심 Topic, 최신성, Link 관계와 발견 비율을 반영하고, Following은 Link한 계정의 최신 Moin을 보여줍니다. 더 보기로 불러온 페이지는 Moin ID 기준으로 합쳐져 같은 글이 중복되지 않으며, 새로고침하면 첫 페이지부터 최신 Flow로 다시 시작합니다.

Moin 작성

  1. Flow 상단의 작성기를 선택합니다.
  2. 본문을 입력하고 필요한 경우 #MOINA처럼 Topic을 붙입니다.
  3. 이미지·MP4·WebM을 선택하고 실제 미리보기를 확인합니다.
  4. 각 미디어가 이 Moin에서 전달하는 정보를 대체 텍스트에 적습니다. 같은 파일을 다른 Moin에서 재사용해도 문맥별 설명은 서로 덮어쓰이지 않습니다. 업로드 중에는 진행 상태를 확인하거나 취소할 수 있습니다.
  5. 공개 범위를 확인하고 Moin 버튼을 누릅니다.
개인정보, 비밀번호, API key와 조직 비밀은 게시하지 마세요. 공개 범위는 게시 전에 다시 확인합니다. 게시물·프로필에 연결하지 않은 업로드가 100개 또는 512 MiB에 도달하면 새 업로드가 제한되므로 기존 media를 연결하거나 관리자가 설정한 정리 시간을 기다립니다.

추천 이유 확인

For Me의 추천 카드에서 Why this Moin?을 열면 Link한 작성자, 팔로우한 Topic, Signal 또는 새로운 발견 같은 이유를 확인할 수 있습니다. 한 번 연 Flow는 당시 점수와 설정을 유지하고, 피드 개인화에서 바꾼 가중치는 새 첫 페이지부터 반영됩니다.

4. 대화와 Signal

동작언제 사용하나요?
Echo원문과 이어지는 의견이나 질문을 남길 때
Remoin원문을 그대로 내 Link에게 알릴 때
공감 / Insight공감이나 새로운 관점을 표시할 때
Pocket개인적으로 다시 볼 내용을 저장할 때

Signal·Pocket·Remoin은 누르는 즉시 화면에 반영됩니다. 서버 저장이 실패하면 이전 상태로 돌아가고 한국어 오류 안내가 표시되므로 반복해서 누르기보다 연결 상태를 확인하세요. 프로필의 Signal 통계에는 공개·게시된 Moin이 받은 반응만 포함되며 비공개·승인 대기·삭제 Moin의 활동은 노출하지 않습니다.

v0.1.5 화면에 제공되는 반응만 사용할 수 있습니다. AI 메뉴는 게시물 자동 요약 기능이 아니라 범용 스트리밍 어시스턴트이며, 결과는 참고용으로 원문을 함께 확인해야 합니다.

5. 검색, Topic과 Pulse

검색 화면에서 Moin, 사람, Topic과 Moim을 한 번에 찾고 유형별 탭으로 결과를 좁힙니다. 정확한 이름·해시태그를 우선하면서 부분 문자열, 비슷한 철자와 본문 관련도를 함께 반영하므로 한국어 문장을 자연스럽게 입력해도 됩니다.

  • Topic을 Link하면 사람을 Link하지 않아도 해당 주제가 For Me 점수에 반영됩니다.
  • Pulse는 최근 7일의 공개 Moin과 Signal을 점수화하고 최근 24시간 활동에 더 큰 가중치를 두어 보여줍니다.
  • Topic 상세 화면에서 관련 Moin과 현재 Link 상태를 확인합니다.

6. Moim과 AI

Moim

Moim은 관심사별 대화 공간입니다. v0.1.5에서는 공개 Moim을 만들고 가입·탈퇴하며 관련 Moin을 모을 수 있습니다.

AI 어시스턴트

AI 메뉴가 보인다면 관리자가 내부 OpenAI-compatible endpoint를 연결한 상태입니다. 범용 대화 응답은 실시간 스트리밍되며 중지 버튼으로 언제든 끊을 수 있습니다. Agent 계정 자동 운영이나 게시물 전용 요약 워크플로는 현재 제공하지 않습니다.

AI 응답은 사실을 보장하지 않습니다. 중요한 판단은 원문, 출처와 조직 정책을 확인한 뒤 수행하세요.

7. 개인 설정

  • 프로필 설정: 표시 이름, 이메일과 소개
  • 피드 개인화: Topic·관계·최신성·새로운 발견 비율과 제외 Topic
  • 알림 설정: In App 유형, Toast, Desktop, Digest와 조용한 시간
  • 화면 및 접근성: 글자 크기, 색상 모드, 움직임 감소
  • 로그인 보안: 로컬 비밀번호 변경과 기존 session 전체 종료

마지막으로 연 메뉴는 같은 브라우저의 local storage에 보관되어 새로고침과 재로그인 뒤 복원됩니다. 다른 브라우저나 기기로 자동 동기화되지는 않습니다. URL을 직접 새로고침해도 현재 메뉴가 유지됩니다.

알림 채널 설정

In App에서 Mention·Signal·Follow·Echo의 알림 센터 노출 여부를 선택하고, 실시간 Toast와 Browser Desktop 알림을 각각 켤 수 있습니다. In App을 꺼도 켜 둔 Toast/Desktop은 계속 받을 수 있습니다. Desktop은 설정 버튼을 누른 사용자 동작에서 브라우저 권한을 허용해야 합니다. 조용한 시간에는 Toast·Desktop 표시만 보류하고 전달 기록은 유지합니다. Digest는 끔·매시간·매일 중 선택하며 매일 시각은 관리자가 정한 서비스 시간대를 사용합니다. Digest를 새로 켜거나 주기·시각을 바꾸면 서버가 변경을 적용한 시점부터 새 구간으로 모으므로 꺼져 있던 동안의 과거 알림이 한꺼번에 오지 않습니다. 승인·보안 알림은 운영상 필수 기록이므로 끌 수 없습니다.

8. 개인 API·MCP 키

  1. 내 API·MCP 키에서 새 키를 만듭니다.
  2. 용도에 필요한 최소 권한과 만료일만 선택합니다.
  3. 한 번만 표시되는 원문 token을 안전한 vault에 보관합니다.
  4. 노출이 의심되면 회전해 새 token으로 교체하거나 즉시 폐기합니다.

회전하면 이전 token은 즉시 사용할 수 없습니다. 키 목록에는 원문이 아니라 식별용 prefix, 권한, 최근 사용 시각과 만료 상태만 표시됩니다.

9. 차단과 신고

원하지 않는 계정은 차단하거나 음소거할 수 있습니다. 정책 위반 Moin, 계정 또는 Moim은 대상과 사유·설명을 제출해 신고할 수 있습니다. v0.1.5 사용자 화면은 신고 처리 상태 알림을 제공하지 않으므로 후속 확인은 운영 담당자 절차를 따릅니다.

팀장 승인 정책은 조직이 켰을 때만 보입니다. 지정된 게시 작업은 제출 → 검토 → 승인 또는 반려 상태로 진행되고, 꺼져 있으면 이 단계와 메뉴가 나타나지 않습니다.

10. 실제 사용자 화면

v0.1.5 최종 릴리스 후보와 테스트 전용 PostgreSQL로 사용자 route를 Light·Dark 테마와 데스크톱·모바일에서 검증한 Playwright 실제 캡처를 제공합니다. 전체 화면과 검증 결과는 manifest에 기록되어 있습니다.

화면 검증 상태를 확인하는 중입니다.

11. 문제 해결

증상확인할 것
로그인이 반복됨브라우저 cookie 허용, 서비스 주소, OIDC redirect URL과 서버 시간
메뉴 접근 거부관리자에게 내 역할과 유효 권한 확인 요청
AI 응답이 시작되지 않음AI 기능 활성화 상태와 내부 endpoint 도달성 확인 요청
알림이 실시간으로 오지 않음WebSocket을 허용하는 reverse proxy와 재연결 상태를 확인합니다. 느린 연결은 자동 재연결되고 읽지 않은 수는 60초마다 REST로 다시 맞춥니다.
Flow 새로고침이 잠시 거부됨같은 계정의 다른 새로고침과 겹친 경우입니다. 화면 안내에 따라 1초 뒤 한 번 다시 시도합니다.
더 보기 뒤 Flow가 처음으로 돌아감Snapshot은 최대 한 시간이지만 반복 새로고침으로 사용자당 활성 3개를 넘겼거나 랭킹 정책이 바뀌면 더 일찍 최신 첫 페이지로 전환될 수 있습니다.
미디어 선택·업로드가 거부됨페이지를 새로고침해 현재 파일 형식·크기·개수 제한을 받고, quota 오류라면 미첨부 100개·512 MiB 여부를 확인합니다.
화면이 오래된 것처럼 보임로그인 화면 버전 확인 후 강력 새로고침

해결되지 않으면 발생 시각, 사용자 아이디, 경로, 화면에 표시된 오류 코드와 서비스 버전을 관리자에게 전달하세요. 비밀번호나 token은 보내지 않습니다.
